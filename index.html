Como usar o Louvores ICNV

🎵 Encontrar e organizar louvores

  • Use a busca para localizar por título ou palavra da letra. Os filtros mostram todos, favoritos ou repertório.
  • Toque em ★ para favoritar e em ♫ para incluir no repertório. No filtro Repertório, segure a alça ↕ e arraste para ordenar.
  • Use a faixa A–Z para pular para a inicial desejada.

➕ Adicionar e editar

  • Use “Adicionar louvor” para inserir título e letra; também dá para importar arquivos Word .docx.
  • Abra um louvor e toque no lápis para editar. O ajuste de cifras permite arrastar os acordes para corrigir o alinhamento.
  • Toque numa cifra compatível para ver o diagrama de violão.

🎸 Usar a cifra

  • Os controles +/− mudam o tom; “Tom original” restaura. A−/A+ ajustam o tamanho da cifra na tela expandida.
  • Dê dois toques na letra para expandir ou recolher a visualização.
  • Se houver link do YouTube ou PDF cadastrado, os atalhos aparecem junto ao louvor; as janelas de vídeo e PDF podem ser movidas.

🖊️ Anotações

  • Na tela expandida, abra ⋮ para ativar a caneta, escolher a borracha, desfazer o último traço ou apagar as anotações do louvor.
  • As anotações ficam salvas neste aparelho para cada louvor.

▶ Apresentação

  • Selecione o filtro Repertório e toque em “Iniciar apresentação”. Os louvores abrem na ordem definida no repertório.
  • Deslize para a esquerda para avançar e para a direita para voltar. Dê dois toques na letra para encerrar e voltar à lista.

⚙️ Preferências, backup e compartilhamento

  • Escolha uma paleta no seletor de temas do cabeçalho.
  • No menu ⋮, exporte um backup completo ou importe um backup para restaurar os dados. “Compartilhar louvores” exporta/importa louvores selecionados separadamente, sem substituir as preferências pessoais.
  • O painel “Controle remoto / Sincronização” fica na tela inicial; requer a configuração do Firebase para funcionar.
